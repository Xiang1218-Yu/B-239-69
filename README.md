# 🎮 3D Tank Battle - 战争雷霆风格坦克大战

一个基于 Vue 3 + Three.js + Cannon.js 开发的 3D 坦克射击游戏，采用战争雷霆的视觉风格和操作方式。

![游戏截图](https://img.shields.io/badge/Game-Tank%20Battle-green)
![技术栈](https://img.shields.io/badge/Vue-3.4-blue)
![Three.js](https://img.shields.io/badge/Three.js-0.160-orange)

## ✨ 特性

- 🎨 **战争雷霆风格UI** - 军绿色调、磨砂玻璃效果、科技感HUD
- 🚗 **真实物理引擎** - 基于 Cannon.js 的重力、碰撞、惯性模拟
- 🎯 **射击系统** - 弹道轨迹、爆炸效果、击中检测
- 🎮 **直观操控** - WASD移动 + 鼠标瞄准，类似主流FPS游戏
- 📊 **完整HUD** - 生命值、弹药、分数、准星、小地图框架
- 🔄 **游戏重启** - 弹药耗尽自动提示，一键重新开始

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0
- npm >= 7.0

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

游戏将在 `http://localhost:3000` 启动

### 构建生产版本

```bash
npm run build
```

## 🎮 游戏操作

### 基础控制

| 操作 | 说明 |
|------|------|
| **W** | 前进 |
| **S** | 后退 |
| **A** | 车体向左旋转 |
| **D** | 车体向右旋转 |
| **按住右键 + 鼠标左右移动** | 控制炮塔水平旋转（360°） |
| **按住右键 + 鼠标上下移动** | 控制炮管仰角 |
| **鼠标左键** | 发射炮弹 |

### 游戏规则

- 🎯 **目标**：击毁地图上的5个木箱目标
- 💥 **弹药**：30发炮弹
- 🏆 **得分**：每击毁一个目标 +100分
- ⚠️ **游戏结束**：弹药耗尽时显示结束界面
- 🔄 **重新开始**：点击"重新开始"按钮恢复游戏

## 🛠️ 技术栈

### 核心框架
- **Vue 3** - 现代化前端框架
- **Vite** - 快速构建工具
- **TypeScript** - 类型安全

### 3D图形
- **Three.js** - 3D渲染引擎
  - PBR材质系统
  - 实时阴影
  - 后期处理（ACES色调映射）
  - 粒子系统

### 物理引擎
- **Cannon.js** - 物理模拟
  - 刚体碰撞
  - 重力系统
  - 阻尼控制

### UI/样式
- **TailwindCSS** - 实用优先的CSS框架
- **自定义军事风格主题**

### 动画
- **GSAP** - 高性能动画库（预留）

## 📁 项目结构

```
tank-battle-3d/
├── src/
│   ├── components/          # Vue组件
│   │   ├── GameCanvas.vue   # 3D游戏画布
│   │   ├── HUD.vue          # 游戏界面HUD
│   │   ├── MainMenu.vue     # 主菜单
│   │   └── GameOver.vue     # 游戏结束界面
│   ├── core/                # 核心游戏逻辑
│   │   └── Game.ts          # 游戏主循环和状态管理
│   ├── entities/            # 游戏实体
│   │   ├── Tank.ts          # 坦克类（玩家）
│   │   ├── Target.ts        # 目标木箱类
│   │   ├── Projectile.ts    # 炮弹类
│   │   └── Terrain.ts       # 地形类
│   ├── systems/             # 游戏系统
│   │   ├── CameraSystem.ts  # 相机跟随系统
│   │   └── InputSystem.ts   # 输入控制系统
│   ├── App.vue              # 根组件
│   ├── main.ts              # 入口文件
│   └── style.css            # 全局样式
├── public/                  # 静态资源
├── index.html               # HTML模板
├── vite.config.ts           # Vite配置
├── tailwind.config.js       # Tailwind配置
├── tsconfig.json            # TypeScript配置
└── package.json             # 项目依赖
```

## 🎯 核心功能实现

### 1. 物理引擎集成
- 坦克刚体物理模拟
- 地面碰撞检测
- 角速度限制（防止翻车）
- 阻尼系统（模拟摩擦力）

### 2. 射击系统
- 弹道物理计算
- 击中距离检测
- 爆炸粒子效果
- 炮弹尾迹渲染

### 3. 相机系统
- 第三人称平滑跟随
- 自动LookAt目标
- 插值算法（Lerp）

### 4. 输入系统
- 键盘WASD控制
- 鼠标右键拖动瞄准
- 防止右键菜单干扰
